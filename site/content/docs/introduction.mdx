## Overview
**A small personal component kit for React, built to match my workflow and preferences.**

`JK-ui` is a close adaptation of **Intent UI** and Laravel UI toolkit [flexiwind](https://flexiwind.unoforge.com/).


## Key Customizations

### Color System
- **Extended Color Palette**: Added and renamed colors to match my preferred naming conventions
- **Semantic Naming**: Restructured color tokens for better clarity and consistency

### Component Styling
- **Refined Components**: Modified default styles of various components to match my design preferences

### Development Experience

- **Iconify Integration**
- **Utility-First**
- **Accessibility**
