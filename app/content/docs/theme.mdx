JK-UI uses **shadcn-standard CSS variables** for maximum compatibility with the Tailwind v4 `@theme` system. Every design token is a CSS variable — change the variable and every component updates.

## shadcn-Standard Tokens

These variables match the shadcn/ui specification and are registered via `@theme inline`:

| Token | Tailwind Utility | Description |
|-------|-----------------|-------------|
| `--background` | `bg-background` | Page background |
| `--foreground` | `text-foreground` | Default text color |
| `--card` | `bg-card` | Card background |
| `--card-foreground` | `text-card-foreground` | Card text |
| `--popover` | `bg-popover` | Popover background |
| `--popover-foreground` | `text-popover-foreground` | Popover text |
| `--primary` | `bg-primary` | Brand color |
| `--primary-foreground` | `text-primary-foreground` | Text on primary |
| `--secondary` | `bg-secondary` | Secondary brand |
| `--secondary-foreground` | `text-secondary-foreground` | Text on secondary |
| `--muted` | `bg-muted` | Subtle background |
| `--muted-foreground` | `text-muted-foreground` | Muted text |
| `--accent` | `bg-accent` | Accent color |
| `--accent-foreground` | `text-accent-foreground` | Text on accent |
| `--destructive` | `bg-destructive` | Destructive actions |
| `--destructive-foreground` | `text-destructive-foreground` | Text on destructive |
| `--border` | `border-border` | Default border |
| `--input` | `border-input` | Input border |
| `--ring` | `ring-ring` | Focus ring |
| `--radius` | `rounded-lg` | Border radius |

## Extended jk-ui Tokens

In addition to shadcn-standard tokens, JK-UI provides extended tokens for advanced styling:

### Background

| Variable | Tailwind Utility | Description |
|----------|-----------------|-------------|
| `--bg` | `bg-bg` | Default background (alias `--background`) |
| `--bg-subtle` | `bg-bg-subtle` | Subtle section backgrounds |
| `--bg-surface` | `bg-bg-surface` | Elevated surfaces |
| `--bg-muted` | `bg-bg-muted` | Muted backgrounds |
| `--overlay` | `bg-overlay` | Modal/drawer overlays |

### Foreground

| Variable | Tailwind Utility | Description |
|----------|-----------------|-------------|
| `--fg-title` | `text-fg-title` | High-emphasis headings |
| `--fg` | `text-fg` | Default body text |
| `--fg-muted` | `text-fg-muted` | Secondary/helper text |

### Border

| Variable | Tailwind Utility | Description |
|----------|-----------------|-------------|

## Border Radius

### shadcn Standard

| Variable | Tailwind Utility | Description |
|----------|-----------------|-------------|
| `--radius` | `rounded-lg` | Default radius |
| `--radius-sm` | `rounded-sm` | Small radius |
| `--radius-md` | `rounded-md` | Medium radius |
| `--radius-lg` | `rounded-lg` | Large radius |
| `--radius-xl` | `rounded-xl` | Extra large radius |

### jk-ui Component Utilities

These map component-specific radii to the shadcn base values. Override the CSS variable to change a single component type.

| Variable | Utility | Default | Used By |
|----------|---------|---------|---------|
| `--ui-radius` | `rounded-ui` | `var(--radius-lg)` | Buttons, inputs, selects, tooltips, badges, alerts, sheets, avatars, etc. |
| `--card-radius` | `rounded-card` | `var(--radius-lg)` | Card component (via `ui-card` utility) |
| `--checkbox-radius` | `rounded-checkbox` | `var(--radius-sm)` | Checkbox indicator |

## Theme Presets

JK-UI ships with 17 built-in theme presets. Select one during `npx jk-ui-cli setup`:

- **default** — Balanced, neutral
- **air** — Light, airy
- **earth** — Warm, earthy
- **fire** — Bold red/orange
- **water** — Cool blue

Each theme provides light and dark variants plus a complete `@theme inline` block.

## Customization

Override any CSS variable at the project, component, or instance level:

### Project-level
```css
:root {
  --primary: var(--color-purple-600);
  --ui-radius: 0.375rem;
}
```

### Component-level
```tsx
<Button className="[--btn-solid-bg:var(--color-purple-600)]">
  Custom
</Button>
```
