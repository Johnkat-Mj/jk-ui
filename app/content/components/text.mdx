## Usage

The Text component provides semantic text styling with intent-based coloring. Use the `intent` prop to apply different text colors, and `elementType` to change the HTML tag.

## API

| Prop | Type | Description |
| --- | --- | --- |
| intent | `muted \| body \| title \| caption \| primary \| secondary \| warning \| destructive` | Semantic color intent for the text. |
| elementType | `p \| span \| div \| label \| small` | HTML tag to render (default: p). |
